# 回路ラインの流れ（試作）

既定はオフ。シャノンスキン対応が有効で、確認済みの顔と対象UUIDが一致する時だけ、追加設定 `enableShannonCircuitFlow` によって描画する。Mod Menu の「回路ラインの淡い流れ（試作）」で切り替えられる。

頭の正面の左右端と左右の側面、腕・脚とその外側レイヤーにある元の不透明な水色ピクセルを選び、1ピクセルを4分割した頂点色のグラデーションとして重ねる。白い外装や別の色には描かない。胴体とjacketの水色はTシャツの布の配色なので、両レイヤーとも対象外にする。腕と胴体の付け根にある薄い水色の縦ラインと、その肩・内側への折り返しもTシャツの布として、確認したUV位置で除外する。肩と前腕の回路は残す。頭の背面は今回の試作範囲外。体はvanillaのcuboidのUVと頂点を使い、肩・脚とその子の服の変換に追従する。slim/普通の腕でも別の寸法を推測せず、実モデルから位置を取得する。

Soft Robot v5 (`shannon-D-soft-robot-v5.png`) も、別の確認済み顔ハッシュで対応する。目の位置・1列幅は従来版と同じ。頭の回路は外側レイヤーのUVと膨らみに合わせ、頬もその手前に描く。紺色の画面の行ごとの陰影を保って元の目を隠し、共通の表情を描く。v5の胴体はロボット外装なので、胸と背中の水色パネルと、体のライン入り版の肩・前腕・脚の不透明な水色の回路を流す（内側・外側レイヤー）。v5の体では水色の色相も確認し、新版の胸パネルの最下行の紺色の枠は除外する。従来版の胴体・脇の布の除外は変えない。従来スキンとv5は同じJARで自動判別する。`shannon-D-lines-10-minimal.png` の頭はv5と同一で、追加された32ピクセルの体の回路にも共通の描画を適用する。

5.6秒で一巡する濃い水色の短い帯を側面から正面へ流す。試作がオンの間は回路の色を淡い水色の共通ベースにし、その上を濃い水色が移動する。静止した元の濃色部分を残すと明るさの呼吸に見えるため、色は全体で同じ滑らかな移動波から求める。帯の前後はグラデーション。目と異なり通常の環境光を使い、発光・光源・外側へのグローは追加しない。元のスキン画像は変更しない。

目の揺らぎは別設定 `enableShannonEyeGradient`（シャノン対応時の既定はオン）。確認したiOSの`ShannonWaterlightCanvas.drawEyes`は3色を固定して投影した目の範囲に追従させ、活動rigは周期動作を加える。MODはその配色を保ち、色の境界と斜め方向を8.4秒で穏やかに揺らす追加の実装。iOSのコードに独立した時間によるgradientの変更があるとは確認できていない。

プレビューはMinecraft実クライアントで正面・斜めの各84時点とオフの画像を撮影する。表情を固定して回路と目の色の動きを見比べる。正面のTシャツの布部分は全84時点でオフと同じ画素であることを検証する。16.8秒で回路3周期と目2周期を取り、継ぎ目でも位相が続く。製品の時間は単調時計、テストはその描画時刻を注入する。撮影用MixinのTAIL順序を本体の状態更新後にし、実際のrenderer.updateRenderStateでも注入した表情と時計が保持されることを確認する。遷移フレームも2 tick待って描画コマンドを反映させる。試作JARは `expressionmod-1.2.0-circuit-preview.jar` として別に保存し、採用済みの表情だけのJARを保持する。
